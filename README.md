# timezone-board

世界时区竖排看板 —— 单文件 HTML，记录关注的国家 / 首都 / 城市，按 UTC 偏移自动竖排。

## 使用

直接打开 `index.html`，或在 GitHub Pages 上访问。

- 输入城市、国家或 IANA 时区（如 `纽约`、`马尔代夫`、`Asia/Tokyo`），回车添加
- 列表按 UTC 偏移自动分组竖排，含夏令时切换后自动重排
- 显示当地日期、跨日提示、与本地时差；本机时区高亮
- 支持 12/24 小时制、显示秒、深浅主题；`time.is` 外链可核对
- 列表保存在浏览器 localStorage

## 技术说明

时间由浏览器内置 IANA 时区数据库计算，无需联网；内置 231 个城市/首都数据。
