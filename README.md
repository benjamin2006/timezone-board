# timezone-board

世界时区看板 —— 单文件 HTML，记录关注的国家 / 首都 / 城市，按白天、夜间分区并按 UTC 偏移排列。

在线访问：https://benjamin2006.github.io/timezone-board/

## 使用

- 输入城市、国家、州名或 IANA 时区（如 `纽约`、`德克萨斯`、`科特迪瓦`、`Asia/Tokyo`），回车添加
- 覆盖 341 个地区：美国 51 州（含 DC）、南非 11 城、加勒比 23 国/地区、南美全部国家、西非主要城市
- 卡片为「国家 城市」同字号，国家在前；当地 06:00–17:59 归白天区，18:00–05:59 归夜间区，跨点自动换区
- 抬头时间固定为北京时间（UTC+8）
- 列表自动保存在浏览器 localStorage，下次打开自动恢复
- 点「分享」生成一条带列表的链接，手机 / 另一台电脑打开即可看到同样的列表（并自动存到那台设备）
- 支持 12/24 小时制、显示秒

## 技术说明

时间由浏览器内置 IANA 时区数据库计算（含夏令时），无需联网。跨设备靠分享链接，仓库本身是静态页面，没有账号系统。
