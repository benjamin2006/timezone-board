# timezone-board

世界时区看板 —— 单文件 HTML，记录关注的国家 / 首都 / 城市，自动按白天、夜间分区并按 UTC 偏移排列。

在线访问：https://benjamin2006.github.io/timezone-board/

## 使用

- 输入城市、国家或 IANA 时区（如 `纽约`、`马尔代夫`、`Asia/Tokyo`），回车添加
- 卡片为「国家 城市」同字号排列，国家在前
- 当地 06:00–17:59 归入白天区，18:00–05:59 归入夜间区，跨过边界时卡片自动换区
- 区内按 UTC 偏移排序，可切换升序 / 降序
- 手机 2 列、桌面 4 列以上，默认 6 个地区在手机上可一屏放下
- 跨日只显示日期与 `+1` / `-1`；本机时区卡片描金边
- 支持 12/24 小时制、显示秒；列表保存在浏览器 localStorage

## 技术说明

时间由浏览器内置 IANA 时区数据库计算（含夏令时），无需联网；内置 231 个城市 / 首都数据。
